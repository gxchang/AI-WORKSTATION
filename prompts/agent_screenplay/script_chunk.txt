# 0. 交付契约

## 0.1 六列总览

输出 6 列各有职能:**镜号**=场镜定位,**景别角度**=摄影机怎么看,**画面描述**=画面里发生什么,**声音**=实际发出的声响,**运镜**=摄影机怎么动,**时长**=多久。剧本里一句话往往横跨多列,按信息类型拆到对应列,不囫囵塞进一列。

分镜表必须直接以 Markdown 输出在对话正文里；正文里的分镜表就是用户确认与后续提交长视频工作台的唯一依据。

## 0.2 三条根原则(贯穿全篇)

**A · 分镜表是镜头执行单,不是剧本翻译**

剧本里"只在文字里有意义、镜头无法直接执行"的措辞(时间感 / 心理感 / 修辞感 / 观众感),必须重新映射为镜头可执行元素(动作 / 拆分 / 时长 / 静默 / 身体信号 / 道具状态)。映射规则见 §4.1。

**B · 信息按"归哪一列承载"分配,不按剧本原句分配**

剧本一句话往往横跨多列,按信息类型拆到对应列(六列职能见 §9.2),不囫囵塞进一列。

**C · 剧本保真优先(高于 B 的列分配优化)**

原剧本里的剧情节点(冲突起因、关键转折、动机定性词、原句台词)必须有镜头承载,**不许丢、不许压、不许改、不许加**。

> 冲突优先级链:**剧本保真 > 列分配优化 > 单镜简洁 > 画面美感**

落地:

- 剧本带引号的台词 → 声音列原句保留,长则拆镜分配,不许只留一半或改写
- 剧本里的关键转折/动机定性词("家境不合适""我们分手吧""她考了第一")→ 必须在分镜里有对应承载镜
- 剧本里没有的画面/台词/转场 → **不许凭空增加**(不要替剧本"补镜""加氛围空镜")

## 0.3 Pre-Read 工作流(三步)

**Step 1 · 通读 + 三类钩子标注(硬约束)**

通读全本,标出每场的三类钩子。这三类是整表合格性硬约束:

- **情绪转折点**:决定 / 惊讶 / 共鸣 / 顿悟 / 崩溃 / 释怀 → 必须有反应镜头承载
- **关键道具**:首次出现、跨场再出现、推动转折、揭示信息的物件(手机、戒指、简历、合同、照片、烟蒂等)→ 必须有特写或近景承载,且必须在该道具被台词/后续动作引用之前或同步出现
- **关键关系节点**:结盟 / 翻脸 / 误会 / 和解 / 揭穿 → 必须有建置或反应镜承载

**Step 2 · 列两张工作表**

- **角色表**:本剧所有角色 + 稳定称呼(如「男主」「林医生」),全程使用这套称呼
- **场次表**:场号 / 地点 / 时间 / 主视点角色(用于景别差判定)

**Step 3 · 分支判定**

- 故事/电影/短剧 → 按 §1~§7 主线执行
- 广告/带货/品牌片 → 叠加 §8 营销分支

## 0.4 全局失败处置(统一声明)

后续章节出现"硬约束 / 必须 / 不许"等强调词时统一适用本条:**任一硬约束未在分镜里找到承载 → 整表不合格、不出表、报错重切**。具体硬约束清单见 §10.1 自检。

Pre-Read 工作底稿不写进输出 md,只是分镜师自己的底稿;但 Step 1 三类钩子的承载校验是出表前的硬关卡。

# 1. 镜号

**承载：**表明场景和镜头号。

`场号-镜号`,场号用阿拉伯数字。示例:`1-3`。

> **决定切几镜的判定规则**见 §2.1 该切的情况 / §2.2 不该切的情况 / §2.3 冲突时的优先级。

# 2. 切镜原则

**承载：**决定剧本里的一段戏拆成几个镜头。

判定流程:**先看是否触发"不该切"的禁令,无禁令再看是否触发"该切"的场景**。

## 2.1 切镜触发场景

### A · 动作层面 —— 同一动作跨镜呈现

| 触发场景 | 切法 |
|-|-|
| 动作匹配(Match on Action) | 剪辑点踩在动作中段(开门把手转到一半就切到门外,而不是关门完成后才切);前一镜写「动作起幅」,后一镜写「动作落幅」 |
| 视线匹配(Eyeline Match) | A 看 → B 镜头,A 的视线方向(上/下/左/右)要和 B 在画面中的相对位置对得上 |
| 方向连续(Screen Direction) | 人物运动方向跨镜保持一致(前一镜从左往右走 → 下一镜继续从左往右走);反向需走 §3.3.4 轴向重置流程 |


### B · 叙事层面 —— 一段戏需要多镜承载情绪

| 触发场景 | 切法 |
|-|-|
| 长台词 / 情绪落点台词 | **单句台词 > 25 字**,或台词跨 2 个语气停顿(逗号/省略号/句号 ≥ 2) | 「说话者 → 听者反应 / 环境细节 → 回切落点」三镜承载,让情绪通过切换被放大,避免一镜读完压平戏 |
| 关键情绪转折 | 决定/惊讶/共鸣/顿悟等戏眼 | 用「动作镜头 + 反应镜头」承载 |
| 关键情绪转折 | 决定 / 惊讶 / 共鸣 / 顿悟 等戏眼,用「动作镜头 + 反应镜头」承载 |
| 看 + 被看(视线接续) | A 看向某物 → 需要 A 的反应镜头 + B 被看到的内容镜头,建立视线逻辑 |

### C · 镜头组逻辑 —— 同一叙事单元需要多视点互补

**镜头组核心**:围绕同一叙事单元,由若干景别/视点不同但功能互补的镜头共同完成。关键不在「多」,在「互补」——视点互补(客观/POV)、景别互补(建置/细节)、主客互补(动作/反应)。

| 触发场景 | 切法 |
|-|-|
| 建立新场景 | 新空间或新人物首次出场,用「全景交代环境 → 中景看人物 → 特写看细节」 |
| 正反打对话 / 关键动作强调 | 多人对话天然成组;标志性动作(开枪、揭面)用「动作 → 物件 → 反应」三镜组 |
| 多视点并存 | 同一动作需要同时呈现手部细节 + 脸部反应 + 整体姿态,单镜装不下,必须拆成「细节镜 + 反应镜 + 主体镜」 |

**组内常用镜头类型(按需取用):** 建置镜头 / 细节镜头 / 主体镜头 / 反应镜头 / 氛围镜头。

## 2.2 禁止切分场景(硬约束)

以下情形禁止切分,必须落在同一个镜号下,通过画面描述与台词字段并列表达:

1. 单个镜头可在 3 秒内完成一个连续动作或一个画面信息
2. 同一角色的连续动作 + 台词,若分镜表「景别角度」列中的**景别 + 角色名 + 朝向**三个字段字面完全一致,禁止切分为多个镜号
3. **同一动作的延展形态**(持续性副词修饰下的同一动作,如「缓缓走过来」「反复擦拭桌面」),视为 1 个动作,用一个镜头拍到底

> 单纯的「动作完成 → 开口说话」「沉默 → 开口」「点头 → 说话」均不构成切分理由。允许切分的前提是以下之一:机位变化、景别跳档、运镜变化承载明确情绪转折、或中间插入对方反应 / 道具特写 / 视点切换。

## 2.3 冲突时的优先级

**§2.2 不切 > §2.1 切**。

当某一段戏同时触发"该切"(§2.1)和"不该切"(§2.2)时,优先听 §2.2 ——硬约束的合并优先于任何切分倾向。

> **声画分层注脚**:同一镜内「画面演 A + 声音放 VO/旁白/心声 B」是纵向叠加,不算冲突、不触发拆镜(如:画面走路 + 声音旁白回忆 → 一镜承载)。
> 
> **剧本保真前提**(根原则 C):剧本里每个台词/动作/转折都必须有镜头承载——这是覆盖率问题,不参与切分判定,但所有切镜结果必须满足这个前提。

# 3. 景别角度

**承载：**画面的景别和角度,奠基故事的流畅度。

## 3.1 受限词表(封闭枚举)

### 3.1.1 景别(七选一,附人体比例锚定)

| 景别 | 锚定 | 职能 |
|-|-|-|
| 远景 | 人物占比 < 1/5,环境为主体 | 让"环境 / 大场面"成为主体 |
| 全景 | 人物全身 + 大量环境 | 让"整体动作 / 多人位置关系"成为主体 |
| 中景 | 人物膝盖以上 | 让"人物上下身动作 / 肢体语言"成为主体 |
| 中近景 | 人物腰部以上 | 让"上半身动作 / 对话姿态 / 过肩关系"成为主体 |
| 近景 | 人物胸部以上 | 让"面部表情 / 手部动作 / 对白情绪"成为主体 |
| 特写 | 人物头部 / 单个器官 | 让"微表情 / 道具关键细节"成为主体 |
| 大特写 | 眼睛 / 嘴唇 / 单个细节 | 让"情绪顶点 / 道具关键纹理"成为主体 |

**景别判据:** 选景别 = 让"画面描述里最关键的视觉信息"获得主体级别的清晰度。N 个等权重个体反应 → 往松走;一处微表情 / 一个动作落点 / 一个道具状态 → 往紧走;环境氛围 / 空间关系 → 全景/远景。

### 3.1.2 朝向(九选一)

正面 / 左 3/4 侧 / 右 3/4 侧 / 左侧面 / 右侧面 / 背面 / 左过肩 / 右过肩 / 同框群像。

**左右判定基准(以观众视角为准):**

- **左/右 3/4 侧**:角色面部转向画面的哪一侧
- **左/右侧面**:角色完全侧脸朝向画面的哪一侧
- **左/右过肩**:作前景的肩部位于画面的哪一侧
- 正面 / 背面 / 同框群像 无方位之分

**朝向判据**:摄影机能看到主体的哪一面。画面描述里出现的身体部位/视图必须落在该朝向的可见面内(如朝向是正面就看不到后背);冲突时拆两镜或改朝向。

### 3.1.3 角度(七选一)

| 角度 | 默认用途 |
|-|-|
| 平视 | 客观陈述、平等对话、日常视角(默认) |
| 俯拍 | 压制 / 渺小 / 弱势(被审视、孤独、被困) |
| 仰拍 | 神化 / 强势 / 仰望(权威人物、英雄出场、压迫感) |
| 贴地 | 局部特写(脚步、低视点物件、宠物视角) |
| 鸟瞰 | 全局概览 / 上帝俯视(大场面、城市、群像) |
| 监视器 | 监控视角 / 偷窥 / 客观第三方记录(悬疑、监控镜头) |
| 鱼眼 | 扭曲变形 / 主观失真(精神错乱、醉酒、梦境、压迫感放大) |

> **判据:** 选角度 = 选观众和角色的"高度关系"。默认平视;打破平视必须有戏剧动机(权力 / 视点 / 失真)。

### 3.1.4 视点

- 默认第三人称客观,景别角度列只写朝向
- 主观镜头:景别角度列写 `【POV:X】` 替代朝向
- 上帝视角:景别角度列写 `【上帝视角】` 替代朝向

## 3.2 字段底线

- **人物镜**:朝向**必须**写明(前加参照主体名,如「男主 右 3/4 侧」「女主 正面」);高度可选,默认平视可省
- **道具/物件/场景镜**:朝向省略是默认;高度**必须**写明,不许空
- **失败例**:`特写 三角尺`(缺高度)/ `全景`(缺朝向缺高度)/ `中近景 俯拍`(缺人物朝向)→ 直接打回
- **合格例**:`特写 三角尺 俯视` / `全景 同框群像 平视` / `中近景 男主 右 3/4 侧 俯拍`

## 3.3 轴向

### 3.3.1 概念与原则

**轴向：**本场角色之间的左右位置关系。建置镜确定各角色「谁在画面左 / 谁在画面右」后,全场所有反打镜的朝向均依此关系,中途不得反转。

**30° 原则：**相邻两镜拍同一主体时,**角度差 ≥ 30° 或景别换一档,任一满足即可，**跨主体接(A → B)不受 30° 约束;运镜镜头在单镜内连续变换角度不算违反。

**合理越轴：非必要不越轴，**若必要，可以在角色完成转身/换位 / 插入中性镜头(正面/纯背面/俯视)缓冲 / 用连续运动镜头跨过轴线。

### 3.3.2 双人对话

**Step 1 · 建置镜**

对话开场首镜须为建置镜:画面包含本场全部对话角色 + 完整空间环境,景别与角度不限(全景 / 中景 / 俯拍 / 鸟瞰等皆可),目的在于交代空间关系与对话主体。例外:同场内已建置过且空间未切换时可省。

**Step 2 · 反打位点表(五选一)**

确定位置声明后,本场所有非建置镜从下表五个位点中选取;每个位点可用于拍 A 也可用于拍 B,只需按位置声明镜像「左 / 右」朝向。内反打与外反打无优先级,按戏剧需求选择;朝向归属难以判定时优先选用内反打。

| 位点 | 画面里能看到什么(判定锚点) | 合法景别角度写法(拍 A 为例,A 在画面左 / B 在画面右) | 配套画面描述要点 | 适用情境 |
|-|-|-|-|-|
| 1 · 外反打 | 被拍者的脸朝向对方,**画面前景必须含对方的肩或后脑一角** | `中景 A 面朝画面右 3/4 侧` / `中近景 A 面朝画面右 3/4 侧` / `近景 A 面朝画面右 3/4 侧` | 画面前景含 B 的右肩(B 在画面右,肩位于画面右侧),A 的脸朝画面右看向 B | 对话主轴,强调两人对位关系 |
| 2 · 内反打 | 仅拍被拍者,**画面内不含对方的任何身体部分** | `中近景 A 正面` / `近景 A 正面` / `特写 A 正面` | 单人入画,A 视线落点在画外右侧(B 的方向),画面内无 B 任何身体部分 | 说话 / 独白 / 情绪戏 |
| 3 · 骑轴 | **画面主体是被拍者的后脑/后背**,对方的脸在前方可见 | `中景 A 背面` / `中近景 A 背面` / `近景 A 背面` | 前景是 A 的后脑/后肩占大半画面,B 的脸在画面纵深处可见、朝镜头方向 | 强调视点 / 压迫感 / 隐藏表情 |
| 4 · 大特写 | 仅拍眼睛 / 嘴唇 / 手等局部,**不含完整脸部** | `特写 A 正面` / `大特写 A 正面` | 画面只剩单一器官(眼/唇/手),无方位参照 | 情绪顶点凝固 |
| 5 · 侧机位双人同框 | 自轴向侧拍,**两人侧脸同框可见对视** | `全景 同框群像 平视` / `中景 同框群像 平视` / `中近景 同框群像 平视` | A 左侧面在画面左、B 右侧面在画面右,两人对视,画面中轴留呼吸空间 | 沉默对峙 / 情绪缓和 / 过渡 |

> **使用提醒**:位置声明 `A=画面左 / B=画面右`。拍 B 时把表里所有"画面右 / 右"镜像为"画面左 / 左"(因 B 在画面右,看向 A 就是面朝画面左,景别角度列写 `B 面朝画面左 3/4 侧`)。"合法景别角度写法"列已穷举所有允许组合,不在此列内的景别组合视为位点错位;"配套画面描述要点"列是写画面描述时必须落到字面的特征,缺失视为位点错位。

**Step 3 · 主配角景别差**

- 主角(视点人物 / 戏份核心)景别更紧(近景 / 特写)
- 配角(对手戏 / 倾听者)景别更松(中近景 / 中景)

**Step 4 · 跳轴失败例 ↔ 合格例**

(位置声明:A=女主 画面左 / B=男主 画面右)

| 错误类型 | ✗ 失败例 | ✓ 合格例 |
|-|-|-|
| 中途跳轴(相邻镜朝向无故反转) | 1-2 用外反打(`近景 A 面朝画面右 3/4 侧`),1-3 突变为 `近景 A 面朝画面左 3/4 侧`(朝向无故反转) | 1-2 用外反打,1-3 切内反打(`近景 A 正面`,不引入反向朝向);或先插入过渡镜让 A 完成转身 |

### 3.3.3 多人对话(≥3 人)

三人及以上不再做严格的双人轴向计算,改用「群像建置 + 按需反打」覆盖:

- **群像建置镜**:全景或中景同框,交代所有人位置,本场首镜必须为群像建置镜
- **按需反打**:任一时刻聚焦哪两人对话,就按 §3.3.2 双人规则给这两人拍反打,其他人在背景虚焦出现
- **回切群像**:每隔 3-5 个反打镜必须回切一次群像建置镜,让观众重新校准位置
- **个体反应镜穿插**:不在当前主对话中的人,情绪反应用独立的单人反应镜承载(内反打 或 大特写),景别角度自由,不参与轴向计算
- **主对话切换**:对话焦点切换(如 A↔B 转到 B↔C)时必须插入过场镜(群像建置镜 或 新主对话方的反应镜),不得从旧反打直接跳到新反打

**位置声明**:首镜群像建置镜末尾追加,格式 `位置:A 画面左 / B 画面中 / C 画面右`(或更多人位置),所有出场角色都要写明。

### 3.3.4 轴向重置(物理位置或视点变化)

任一镜内出现以下情况,视为轴向重置,必须按本节处理:

- **角色物理移动**:从沙发走到窗边、追出门外、走近对方等位置变化
- **新角色加入**:原对话外的角色进入空间(进门、闯入、被叫来),需要重新安排左右位置
- **视点切换(POV 翻转)**:从 A 的 POV 切到 B 的 POV,画面左右镜像翻转,客观位置未变但画面方位反转

**硬约束**:轴向重置不得通过「上一镜旧位置 → 下一镜新位置」硬跳实现,必须有以下两类过渡镜之一承载:

1. **跟移镜**:摄影机跟随移动角色,完整呈现位置变化过程,运镜列写明「跟」或「移」
2. **建置回切**:角色就位后,切一个建置镜(中景或全景同框),重新交代新位置,然后才能开始新一轮反打

**位置声明二次追加**:在过渡镜的画面描述末尾追加新的位置声明,覆盖之前的声明。

# 4. 画面描述

**承载：**写给审稿人看的客观描述。

## 4.1 根本判据(剧本叙事语言 → 镜头执行元素的映射)

只写**镜头能拍到、能被观众用眼睛看到的视觉信息**。任何属于"剧本叙事语言"而非"镜头执行元素"的内容,重新映射;但**不许把剧本里的实质剧情信息映射没了**:

| 剧本里的叙事语言 | 映射规则 |
|-|-|
| 时间感:两秒后 / 良久 / 片刻 / 随即 | **改写**:具体时间度量(两秒后 / 三分钟)→ 拆两镜 / 调长镜头时长;节奏感措辞(片刻 / 良久 / 随即 / 缓缓)→ 保留,作为画面停留指引 |
| 心理感:他想起 / 暗自决定 / 五味杂陈 | **改写**为身体信号(眼神 / 微表情 / 手部动作 / 呼吸) |
| 修辞感:命运齿轮 / 时光凝固 / 空气尴尬 | **改写**为可拍的画面元素——"空气尴尬"→ 两人沉默 + 避开目光 + 小动作;"时光凝固"→ 特写定格 + 环境音骤停;无具体意图时按观众感处理(删除) |
| 观众感:令人揪心 / 让人动容 | **删除**(评论性语言,无画面信息) |
| 镜头语言:他的脸特写 / 镜头推近 | **删除**(景别/运镜归到独立列) |
| 无声反应:`(疑惑)` / `(沉默)` / `(错愕)` | **迁移到画面描述列**,翻译成具体身体信号(眉头微皱 / 嘴唇张了张 / 瞳孔放大);声音列留空 |
| 心声 / 旁白 / OS / VO | **迁移到声音列**,原句保留;按 §5.1 写法区分: `心声·角色名:"…"` / `旁白:"…"` / `画外·角色名:"…"` |

## 4.2 正反示例

| 判定 | 剧本原文 | 画面列 | 声音列 | 说明 |
|-|-|-|-|-|
| ✗ | 男主心里五味杂陈,回想起和父亲的争吵 | (照抄) | — | 心理活动,应改写为身体信号 |
| ✗ | 命运的齿轮开始转动,空气仿佛凝固 | (照抄) | — | 修辞感+观众感,删除或改写为可拍元素 |
| ✓ | `陈明旭(错愕)` | 陈明旭面露错愕,嘴唇张了张 | 留空 | 无声反应迁移到画面列 |
| ✓ | `V.O.·女主:"他真的回来了"` | 女主眼神骤然睁大,嘴唇微张 | `V.O.·女主:"他真的回来了"` | 声画分层,画面给身体信号,声音原句保留 |

# 5. 声音

**承载：**实际在镜头里被观众耳朵听到的声响。

## 5.1 类型与写法

| 类型 | 写法 | 示例 |
|-|-|-|
| 对白 | `角色名:"台词"` | `男主:"今天好累"` |
| 旁白 | `旁白:"文本"` | `旁白:"那一年我十七岁"` |
| 内心独白 / 心声 | `心声·角色名:"独白"`(角色本人嗓音,画外播出) | `心声·女主:"他真的回来了"` |
| 画外音(非心声) | `画外·角色名:"…"` 或 `画外·音源:"…"`(画外角色对白或非角色音源) | `画外·男主:"等等我!"` / `画外·电话:"您好,这里是医院"` |
| 音效 | 指向具体动作或物件的瞬时声响,纯名词短语 | `面包掰开的轻响` / `瓷杯放回桌面的轻响` |
| 环境 | 持续性的场景背景声,不指向具体动作 | `远处车流` / `风扇转动声响` |
| 无声音 | **整格留空** | (留空) |

**补充约定:**

- **多源同类**:同类型声音用 `+` 拼接(`远处车流 + 风声`)
- **多类型并存**:对白 + 音效用**换行**分隔,不用 `+`
- **字幕**:画面上叠加的文字字幕(时间/地点/身份)归画面描述列,不写在声音列

## 5.2 通用约束

- 对白 / 心声 / 旁白原文逐字一致,不增词、不删词、不改标点、不改语气词
- 允许对白跨镜头承载(具体格式见 §5.4)
- 配乐 / 背景音乐相关描述不写
- 声画分层不算冲突,见 §2.3 注脚

## 5.3 声画时序归属(硬约束)

| 声音类型 | 画面描述必须满足 |
|-|-|
| 对白 `角色名:"…"` | 画面里出现该角色(说话者面部 / 过肩 / 听者反应) |
| 心声 `心声·角色名:"…"` | 画面里出现该角色(嘴未动),或画面是该角色 POV |
| 画外音 `画外·X:"…"` | 画面里看不到 X 本人,但场景上下文能解释声源 |
| 旁白 | 不强制出现旁白者,但画面内容应承载旁白所述情境 |
| 音效(动作类) | 画面里必须有产生该音效的动作或物件 |
| 环境声 | 画面所在场景能合理产生该环境声 |

**时序原则:** 每段声音的"开始-持续-结束"必须能在画面镜头序列上找到合理对应,判定依据是**声源的物理时长**,不是修辞需要。

**长声处理**:声音物理时长 > 单镜时长 → 按 §5.4 分类承接;**短促音效**(拍击、撞击、关门、瓷杯放下,物理上 ≤ 1s)不许在下一镜以"余响 / 回响"延续。

## 5.4 长声跨镜处理

声音物理时长 > 单镜时长时,按声音类型用不同格式承接:

| 声音类型 | 承接模式 | 首镜写法 | 中间镜写法 | 末镜写法 | 示例 |
|-|-|-|-|-|-|
| 对白 | 跨镜起止标记 | `角色名:"完整台词"` | `↓台词承接` | `↓台词承接(止)` | 1-1 `男主:"你是不是不爱我了"` → 1-2 `↓台词承接` → 1-3 `↓台词承接(止)` |
| 心声 / 旁白 | 拆镜分摊(按自然停顿点拆,逐字承接) | `心声·角色名:"片段1"` | `心声·角色名:"片段2"` | `心声·角色名:"片段3"` | 1-1 `心声·女主:"那一年的夏天"` → 1-2 `心声·女主:"我以为我们会一直在一起"` → 1-3 `心声·女主:"可是他真的回来了吗"` |
| 环境声 | 场首声明 + 后续省略 | `环境声(全场持续)` | 留空(沿用场首,有新增声音则只写新增) | `(全场持续止)` 或 切场时声明新环境 | 2-1 `超市背景嘈杂声(全场持续)` → 2-2 留空 → 2-3 `罐头碰撞架子的轻响` → 2-5 `(全场持续止)` + `街道车流` |

# 6. 运镜

**承载：**摄影机怎么动,服务于戏剧动机。

## 6.1 枚举(九选一)

固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 / 甩镜。

## 6.2 运镜动机表(硬约束)

运镜服务于戏剧动机。下表给出常见情绪节点的运镜默认倾向,偏离默认必须有戏剧动机:

| 情绪节点 / 戏码 | 运镜默认倾向 | 运镜原义 |
|-|-|-|
| 情绪压迫升级(对峙、被审视、被压制) | 推 | 压缩 / 聚焦 |
| 情绪释放 / 抽离(高潮后、孤独、收尾) | 拉 | 释放 / 抽离 |
| 人物行进(走入、走出、穿越空间) | 跟 | 同步行动 |
| 视线引导(A 看向 B 的过渡、空间扫描) | 摇 / 移 | 视线引导 / 空间扫描 |
| 群体反应 / 混乱场面 | 手持 | 紧张真实 |
| 冲击瞬间的扩散感(拍击、爆破、瑟缩) | 拉(从冲击点拉开) | 释放 / 抽离 |
| 急速视线转移 / 强烈冲击 / 时空切换 / 慌乱失控 | 甩镜 | 急速视线转换 / 注意力强行跳转 |
| 客观陈述、平静叙述、静默凝视 | 固定 | 客观稳定 |
| 俯瞰 / 抬升的全知视角(楼宇间转场、群像建置) | 升降 | 高度变化 / 全知视角 |

## 6.3 一镜带多信息(优于硬切两镜)

当两个信息在同一镜头内可被同时承载,且**叙事上有因果**(脸的情绪 ← 手的动作引发 / 老师讲课 → 引出学生反应),鼓励用运镜在一镜内串起多个信息。

## 6.4 焦距变化

仅在有需求时叠加在运镜列。

**焦距变化 ≠ 运镜**:运镜是摄影机机身的物理移动,焦距变化是镜头组的光学操作(变焦/拉焦),两者属于不同概念。但叙事效果上常与运镜复合使用,因此当镜头里出现焦距变化时,可在运镜列叠加标注:

| 类型 | 物理原理 | 运镜列写法 | 适用场景 |
|-|-|-|-|
| 拉焦(Rack Focus) | 机身不动,焦平面前后变化(前景虚→实 / 后景实→虚) | `固定 + 拉焦` | 前后景同框,通过焦平面切换揭示信息(前景男主看向画外 → 后景女主推门入焦) |
| 变焦(Zoom In/Out) | 机身不动,镜头焦距拉长/缩短,视场角缩放 | `固定 + 变焦推 / 固定 + 变焦拉` | 强行聚焦或抽离,视觉上像"推/拉"但物理上机身不动(常用于纪实风、监控感) |
| 希区柯克变焦(Dolly Zoom) | **机身物理推/拉 + 镜头反向变焦**,主体大小不变但背景扭曲 | `推 + 反向变焦` 或 `拉 + 反向变焦` | 心理冲击瞬间(顿悟、眩晕、空间错乱、惊恐凝视) |

# 7. 时长

**承载：**时长由"画面内能否自然完成所承载的内容"决定。

## 7.1 基本规则

- **范围**:下限 1s,封顶 15s
- **单位**:整数 + `s`,小数向上取整(2.2s → 3s)
- **节奏基线**：多数镜头可落在 2~6s,但该范围不是硬限制；如画面动作、人物反应、信息扫描或台词需要更长时间,必须按实际承载内容延长。
- **1s** 仅用于瞬时信息 / 情绪顶点 / 微表情切换,不允许整表大量 1s 充数
- **5s 无台词硬上限**:翻文件 / 凝视 / 等待 等长动作,默认用运镜带过(推/拉/移)或拆 2 镜,不要为"完整呈现"拉到 5s 以上
- **长镜头**:上限 15s,必须有明确叙事动机,画面描述写明"长镜头·一镜到底"
- **声画时序**:声音不能反向拉长画面——1s 内短促音效的画面,不应配 2s 以上的镜头时长

## 7.2 评估因素

按"画面要装下什么"估算时长,取以下四者的最大值作为镜头基础时长:

| 因素 | 估算方法 |
|-|-|
| 台词 / 旁白 / 心声 | 按角色 + 语态分档计算,见下表;明显停顿 / 省略号 / 语气延展按情绪节奏额外加时,不机械按字数 |
| 动作复杂度 | 动作完成所需的物理时间,关键行为、动作转换需完整呈现 |
| 信息扫描 | 按观众看清人物位置、道具状态、产品信息、字幕信息或多人关系所需时间估算。 |
| 情绪停留 | 角色在台词前后出现停顿、迟疑、压抑、反应、凝视、避开视线等情绪落点时,必须额外保留 1~3s。 |

台词时长分档(中文字数 ÷ 每秒字数 + 0.5s 收尾):

| 类型 | 速率 | 适用 |
|-|-|-|
| 旁白 / 广播 / 系统播报 | 5 字/秒 | 节目旁白、广播通知、系统提示音(语速最快、字正腔圆) |
| 普通对白 / 心声 | 4.5 字/秒 | 角色之间对话、内心独白(标准口播) |
| 情绪段 / 群像反应 | 3.5 字/秒 | 哭腔、喊叫、停顿、气音、震惊后断续(有情绪缓冲) |

硬约束:
- 有台词镜时长 = max(画面动作所需, 台词字数 ÷ 对应速率 + 0.5s 收尾)
- 公式算出 >15s → 必须按 §2 切镜原则拆镜,禁止压缩台词、禁止删字
- 无台词镜走 §7.1 上限(5s),不受本节约束

## 7.3 情绪节奏修正(微调,不改变量级)

- **快节奏场**(冲突 / 追逐 / 争吵 / 紧张推进):整场镜头时长**酌情下调**,通过快切强化压迫感
- **慢节奏场**(悲伤 / 凝重 / 余韵 / 情感落点):整场镜头时长**酌情上调**,通过停留放大情绪
- 修正幅度由 AI 按戏剧需求自行把握,**不允许大幅突破 §7.1 的硬上限**

1. 声音不能反向拉长画面——1s 内短促音效的画面,不应配 2s 以上的镜头时长

# 8. 营销分支

**承载：**广告 / 带货 / 品牌片在主线规则之上的额外约束。

> 本节在 §1~§7 基础规则之上叠加,基础规则不重复说明。仅当剧本类型为广告 / 带货 / 品牌片时启用。

## 8.1 核心原则

- **卖点前置**:核心卖点在前 5 秒内呈现
- **痛点共鸣**:先展示问题/痛点,再引出解决方案
- **场景化呈现**:真实生活场景中的使用
- **信任背书**:用户评价、权威认证、销量数据等可见元素
- **行动号召**:结尾明确 CTA

## 8.2 镜头设计

- **产品展示**:360° 旋转外观、微距特写材质细节、使用场景演示功能、前后对比效果
- **信息呈现**:关键卖点用大字幕强调,价格/优惠用醒目配色,品牌 Logo 首尾露出
- **转化引导**:限时/限量制造紧迫感,二维码/链接位置预留

## 8.3 额外约束

- 产品名称、卖点、价格等关键信息必须**准确呈现**(不许改写)
- 代言人 / 演员展现**真实使用场景**
- **首屏 3 秒内必须出现核心卖点 Insert 镜**

# 9. 输出格式

**承载：**分镜表最终交付的 Markdown 文件结构与字段规范。

## 9.1 整体结构

输出格式:**Markdown(.md)**。每场独立一个区块,区块顺序 = 剧本场次顺序。

分镜表首行必须是主标题:

```Plain Text
# {name}故事板
```

**场表头格式:** 一行三段,用 `｜` 分隔(空格+全角竖线+空格):

```Plain Text
场景X ｜ 地点 ｜ 时间

| 镜号 | 景别角度 | 画面描述 | 声音 | 运镜 | 时长 |
|---|---|---|---|---|---|
| X-1 | … | … | … | … | … |
| X-2 | … | … | … | … | … |
```

**三段标签写法:**

| 段 | 写法 |
|-|-|
| 场集 | 中文数字(场景一 / 场景二 / 场景三 ...) |
| 地点 | 自由短语(老城市街道 / 写字楼电梯间 / 江边码头) |
| 时间 | 四选一:日内 / 日外 / 夜内 / 夜外。特殊时段允许"黄昏·外""清晨·内""黎明·外"等加点写法 |

**排版:** 场标行与表格之间空一行;场与场之间空一行;每场重复完整的表头 + 分隔行。

## 9.2 六列字段速查(细则见对应章节)

| 列 | 速查 | 详细规则 |
|-|-|-|
| 镜号 | `场号-镜号`,场号阿拉伯数字 | §1 |
| 景别角度 | `景别 朝向[+高度]`,人物镜朝向必写、道具/场景镜高度必写;主观镜头朝向位置写 `【POV:X】`;上帝视角写 `【上帝视角】` | §3.1 / §3.2 |
| 画面描述 | 只写镜头能拍到的视觉信息;不写景别/朝向/视点/运镜/时间副词/心理活动 | §4 |
| 声音 | 实际发出的声响;无声整格留空;长台词跨镜分摊不删字 | §5 |
| 运镜 | 九选一:固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 / 甩镜;焦距变化叠加标注 | §6 |
| 时长 | 整数 + `s`,2~4s 基线,1s 仅留情绪顶点 | §7 |

## 9.3 全局格式硬约束

- **占位符保真**:任何 `[ph_xxx_ph]` 形式占位符在镜号、景别角度、画面、声音、运镜列**必须 byte-for-byte 原样保留**——不许翻译、不许替换为猜测真名、不许替换为通用代称("某某""他/她")、不许改大小写、不许加格式包裹
- **角色名一致性**:每镜画面列、声音列冒号前出现的角色名必须**一致**;全程从 §0.4 Step 2 角色表里取名,不许新增、不许改写;跨场跨镜统一称呼("男主"就一直是"男主",不许中途变成"林医生"再变回来)

# 10. 自检与失败处置

## 10.1 自检(交付前一遍 · 硬约束清单)

输出分镜表后,自己逐场扫一遍,逐条核对以下硬约束。**任一条不过 → 改后再交,改不了 → 重切**。

| # | 硬约束 | 判定 |
|-|-|-|
| 1 | **剧本保真**(根原则 C) | 剧本里每个台词/动作/转折是否都有镜头承载?台词是否原句保留?有没有凭空加镜? |
| 2 | **景别角度字段底线**(§3.2) | 人物镜是否写明朝向?道具/场景镜是否写明高度?有没有"只剩景别"的镜? |
| 3 | **画面描述无叙事语言**(§4.1) | 时间感/心理感/修辞感/观众感/镜头语言/无声反应/心声·旁白·画外音 这 7 类是否按映射表处理? |
| 4 | **声画时序与原句保留**(§5) | 声音物理时长是否对得上画面?短促音效是否被错误延续?长声是否按 §5.4 跨镜处理?对白/心声/旁白是否原句保留在声音列? |
| 5 | **占位符与角色名一致性**(§9.3) | `[ph_xxx_ph]` 是否原样保留?角色名跨场跨镜是否统一称呼? |
| 6 | **单场镜头数兜底** | 单场镜头数是否落在「秒数÷8 ~ 秒数÷2」区间内?(基线 ÷4,按 §7.1 2~4s/镜;少于此偷懒、多于此堆切;长镜头不受下界约束) |
| 7 | **有台词镜时长下限**(§7.2) | 每个有台词镜:时长 ≥ ⌈台词字数 ÷ 速率⌉ + 0.5s 收尾(旁白/广播/系统 ÷5、对白/心声 ÷4.5、情绪段/哭喊/停顿 ÷3.5)?算出 >15s 是否已按 §2 拆镜? |
