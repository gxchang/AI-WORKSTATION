# skill：故事短片-剧本创作技巧

## 1. 适用范围与硬性约束

### 描述
当用户已经确认故事大纲，或已提供等价的故事设定与约束（人物、世界观、关键情节等）后，参照此技巧将其转化为完整的拍摄剧本。剧本是连接故事构思与视觉呈现的关键桥梁，为后续分镜设计提供详细依据。

### 重要约束
- 优先级：用户已确认的设定/指令 > 已确认的大纲 > 本技巧建议；只补空缺，不得推翻或改写
- 扩写原则：大纲提供情节点与因果（骨架）；剧本把其扩成可拍场景（动作/对白/调度/信息呈现）。适当扩写细节与视觉段落，但必须保持情节点功能与因果不变，不得替换动机/因果/结局或转移关键冲突到无关支线
- 必保留项：大纲点名的关键动作、标志性表情/反应、关键台词、关键信息点（尤其结尾用于收束角色弧线的细节）必须出现；需要更强视觉冲击时只能叠加特写/动作/调度，不能挤掉原要点

## 2. 创作总原则

### 2.1 基于大纲 (Outline-Based)
- **严格遵循**已确认的故事大纲，不偏离核心情节
- 保持故事的主题和情感基调一致
- 在大纲框架内丰富细节，不随意增删主要情节

### 2.2 细节丰富 (Detail-Rich)
- 补充具体的动作细节，让角色"动"起来
- 描述表情神态，传递角色内心活动
- 丰富环境细节，增强画面感和沉浸感
- 添加感官细节（视觉、听觉、触觉等）

### 2.3 对话自然 (Natural Dialogue)
- 对话符合角色的身份、年龄、性格
- 避免生硬的说教和刻意的"金句"
- 对话推动剧情发展或揭示角色关系
- 留白和停顿也是对话的一部分

### 2.4 节奏把控 (Pacing Control)
- **起**：快速建立情境，引入角色
- **承**：情节发展，矛盾积累
- **转**：高潮或转折点，情绪爆发
- **合**：收尾，留下余韵

### 2.5 可拍摄性 (Shootability)
- 只写镜头可验证的信息：动作描述中只允许出现三类内容：
1. 可见动作与表情
2. 可闻声音与台词
3. 可被当前场景直接验证的物理细节
   禁止直接写人物心理、主观判断、作者解释、抽象感受。
- 把“内在认知”改写为“外在证据”：不要写“觉得、意识到、明白、想起、痛苦、害怕、被背叛”等脑内信息。改写为停顿、视线、动作、道具、环境变化、对白，或能被镜头直接捕捉的证据。
- 跨时间的比较必须先建立画面锚点：不要直接写“和十年前的一模一样”“像他小时候见过的那把刀”。必须先在前文或当前场景中提供可见依据，再完成比较。依据可以是：旧照片、旧物、伤痕、编号、缺角、录音、新闻画面、证人对白，或独立成场的闪回。比较时优先写具体可见细节，不要写抽象结论。
- 用户输入中的不可拍信息，要转译，不要硬删：如果用户原始输入里本来就包含回忆、情绪判断、主观感受、抽象概括、人物认知等不可直接拍到的信息，不要简单删除或忽略，而要将其**显式转译**为可拍表达。优先转成当前场景中的动作、表情、对白、道具、环境细节、关系变化；必要时可扩成独立场景、插入画面、旁证信息或闪回段落。
- 闪回与插入信息使用规则：这类补充段落必须服务于当前情节，补充角色当下判断、关系变化或信息揭示，不能把关键因果偷渡成一句作者解释。段落结束后，要回到当前时空，并让角色在当下有可见反应或动作承接。
- 用行为代替情绪标签：不要直接写“他很痛苦”“她非常愤怒”“他觉得自己被背叛了”。优先写人物的行为反应和语言反应，让情绪由表演和画面成立。
- 用具体细节代替抽象概念：不要写“熟悉感”“命运的嘲讽”“无尽的苦难”“压抑的气氛”。改写为具体、可见、可听的细节，例如伤口、污渍、物件摆放、空间距离、停顿、呼吸、噪音、灯光状态、人物动作。
- 不给导演写死分镜：除非信息呈现依赖特殊镜头，否则不要密集指定“特写 / 推镜 / 摇镜 / 慢动作 / 蒙太奇”。
- 除台词外，画面描述禁止出现比喻、成语。只交代场面调度、关键信息、人物动作和节奏点，把镜头选择留给导演与分镜。

**自检规则**
生成剧本后，逐句检查：
1. 摄影机能拍到吗？
2. 麦克风能录到吗？
3. 演员能演出来吗？
4. 这一句写的是“角色知道了什么”，还是“观众看到了什么”？
只要前 3 项都不成立，或第 4 项是前者，就必须改写。

**高频错误词（出现时优先检查是否不可拍）**
觉得、意识到、明白、想起、仿佛、似乎、痛苦、难过、愤怒、害怕、背叛、熟悉、命运、压抑、一模一样。
这些词不是绝对禁用，**但只要它们表达的是角色脑内判断而非可见事实，就要改写。**

### 2.6 剧情逻辑一致性 (Story Logic Consistency)

- 剧本不仅要“拍得出来”，还要“讲得通”。任何关键事件都必须满足：观众能看见原因，角色的反应符合已知信息，结果符合故事设定。
- 先判定作品的世界规则，再决定事件能否成立：
  - **现实主义 / 一般都市 / 古风 / 非超现实科幻**：默认遵守现实物理规律、日常常识、社会规则、基础技术边界。禁止无铺垫出现“按一下按钮物体直接消失”“人物突然隔空获知信息”“伤势瞬间恢复”等结果。
  - **奇幻 / 超现实 / 高概念科幻**：允许非常规事件，但必须先建立规则，再按规则执行。至少交代清楚**触发条件、作用范围、限制或代价**中的两项；后文不得临时改规则。
- 关键结果前必须有可见成因，不得跳过中间必要步骤。不要只写“结果发生了”，要让观众知道它为什么会发生。
- 所有“异常高效”的结果都必须特别审查：如果某动作明显超出现实效率或常理，就必须补足机制、工具、铺垫或代价；若故事并非该类型，直接改回符合常理的表达。
- 角色行为必须符合其身份、目标、处境和刚刚获得的信息。禁止为了推进剧情，让角色突然做出明显违背常识、职业能力、已知风险判断的决定。
- 角色知道什么，必须有来源。信息来源通常只能是：亲眼所见、亲耳所闻、他人明确告知、文件/设备记录、既有经验、清晰的推理链。禁止角色在没有来源的情况下说出本不该知道的信息。
- 时间信息必须前后一致。凡出现“几分钟后 / 两小时后 / 两天后 / 次日 / 上周 / 当晚”等明确时间标记，后文必须严格沿用，不得随意缩短、拉长或改口。
- 转折可以突然，但不能无因。转折前至少要有一个前置信号：异常行为、可疑道具、反常对白、被忽略的细节、世界规则说明、倒计时、限制条件等。

### 2.7 故事短片剧本的常见关注点

#### 角色塑造
- 通过对话和动作展现角色性格
- 首次出场需有外观和状态描述
- 角色行为符合其性格逻辑
- 角色在故事中有清晰的成长弧线

#### 情感冲突
- 设置情感张力和冲突点
- 通过细节传递情绪变化
- 情绪提示标注关键转折点
- 冲突源于角色的愿望与现实的对立

#### 情节转折
- 设计合理的情节转折和高潮
- 转折前有铺垫，转折后有影响
- 避免突兀的剧情跳跃
- 转折点是角色成长的契机

#### 情感共鸣
- 引发观众的情感共鸣
- 关注普世情感（爱、离别、成长、梦想等）
- 结尾留有回味空间
- 通过具体细节而非概念打动人

## 3. 剧本核心逻辑

### 3.1 冲突设计原理

**戏剧冲突的本质**：「不可兼容的价值对撞」
- 冲突不是简单的打架或争吵，而是**价值观的碰撞**
- 冲突源于角色的**愿望与现实的对立**
- 冲突必须扎根于**真实人生的底层逻辑**

**冲突设计公式**：
```
主角想要什么（愿望）+ 什么阻止了他（阻碍）= 戏剧冲突
```

**冲突类型**：
- **人物 vs 人物**：价值观对立（如：坚守正义 vs 不择手段）
- **人物 vs 环境**：时代困境、社会压力（如：下岗潮中的生存挣扎）
- **人物 vs 自我**：内心挣扎、道德抉择（如：救人 vs 自保）

### 3.2 戏剧张力构建

**张力的本质**：「未落地的代价带来的持续拉扯」
- 观众知道主角的选择会有代价
- 代价迟迟不落地，形成持续的张力
- 张力通过**选择与代价的逻辑**维持

**张力构建方法**：
1. **明确代价**：让观众知道主角面临什么风险
2. **延迟兑现**：代价不要立即发生，保持悬念
3. **递进升级**：代价随着情节发展越来越大

### 3.3 反转设计原理

**反转的本质**：「选择与代价的逻辑重构」
- 反转不是突兀的转折，而是**前期铺垫的必然结果**
- 反转必须改变观众对**选择和代价**的认知
- 反转后，故事的**价值观层面**发生重构

**反转设计原则**：
- **前置铺垫**：反转的线索必须在前期埋下
- **逻辑自洽**：反转必须符合故事内在逻辑
- **情感共振**：反转必须触动观众的情感

### 3.4 选择与反馈链条

**核心骨架**：每个选择必须有明确的反馈

| 故事类型 | 选择特点 | 反馈特点 | 示例 |
|---------|---------|---------|------|
| **流量向** | 简单直接 | 即时收益、零延迟爽感 | 复仇成功、获得偏爱 |
| **经典向** | 复杂艰难 | 不可逆代价、驱动成长 | 失去亲人、获得成长 |
| **爆米花** | 正义明确 | 简单胜利、正向反馈 | 打败反派、守护家人 |

**剧本中的体现**：
- 每个场景都包含一个**小选择**
- 选择累积形成**角色成长弧线**
- 最终选择决定**故事主题落地**

### 3.5 情绪落地方法

**情绪的本质**：让观众"看见自己"
- 要么实现**代偿性满足**（现实中难以达成）
- 要么完成**自我和解**（与生活的和解）

**情绪落地技巧**：
1. **具体细节**：用具体动作、物品传递情感，而非概念
2. **以小见大**：通过小人物、小事折射大情感
3. **情绪递进**：铺垫 → 升温 → 爆发 → 回味
4. **留白艺术**：结尾给观众回味空间

## 4. 从大纲到剧本的写作方法

### 4.1 场景拆解方法
根据大纲中的情节点，将故事拆解为具体场景：

**拆解原则**：
- 每个情节点优先对应1个场景；关键节点可拆为2个场景以承载转折或情绪爆发；主客观场景变化应该有单独的场景，客观场景指当前正在发生的客观事实所在时空，主观场景指类似回忆、梦境、想象、幻觉等非当前的时空
- 场景数量建议：故事短片通常为 5–8 个核心场景
- 每个场景必须有明确的戏剧功能（建置/冲突/转折/高潮/结局）

**场景功能对照**：
| 情节点 | 场景功能 | 剧本重点 |
|-------|---------|---------|
| 开场画面 | 建置 | 环境氛围、主角日常状态 |
| 触发事件 | 打破平衡 | 具体事件、主角反应 |
| 第一情节点 | 行动决定 | 主角的选择和行动 |
| 中点 | 转折/发现 | 情绪转变、新信息揭示 |
| 低谷 | 最大困境 | 情感张力、内心挣扎 |
| 高潮 | 核心冲突解决 | 最激烈的对抗/选择 |
| 结局 | 新平衡 | 情感释放、主题落地 |

### 4.2 场景设计技巧

#### 场景构建三要素
1. **空间设计**：选择能体现情绪、推动情节的地点
2. **时间设计**：利用一天中的不同时段营造氛围（清晨的希望/夜晚的孤独）
3. **冲突设计**：每个场景必须包含某种形式的冲突（人物vs人物/人物vs环境/人物vs自我）

#### 场景节奏控制
- **开场场景**：快速建立情境，开场尽快抓住观众
- **中间场景**：张弛有度，情感逐步积累
- **高潮场景**：情绪最激烈，冲突最尖锐
- **结尾场景**：留白，给观众回味空间

### 4.3 类型片剧本技巧

根据故事类型，运用对应的剧本技巧：

| 类型 | 剧本重点 | 技巧提示 |
|-----|---------|---------|
| **情感片** | 人物关系、共情纽带 | 制造情感冲突，角色不完美，通过细节传递情感变化 |
| **悬疑片** | 信息控制、逻辑闭环 | 误导性铺垫、延迟真相、伏笔与揭秘的对应 |
| **恐怖片** | 氛围营造、心理暗示 | 未知性、异化日常场景、视听语言设计 |
| **喜剧片** | 笑点构建、节奏明快 | 反差、夸张、人物搭配（"没头脑"+"不高兴"） |
| **科幻片** | 世界观设定、视觉奇观 | 高概念设定、科学依据、想象力展现 |

### 4.4 对话写作技巧
**凡是信息揭示、关系变化、谈判对抗、误会澄清、约定/命令/请求等需要语言推动的情节，必须写出有效对话，不能只写动作。**

#### 对话功能
- **推进情节**：对话推动故事发展
- **揭示角色**：对话展现性格特点
- **传递信息**：自然融入背景信息
- **制造冲突**：对话中的对抗和张力

#### 对话原则
- **符合身份**：年龄、职业、性格决定说话方式
- **言外之意**：好的对话有潜台词
- **留白艺术**：停顿、沉默也是对话的一部分
- **避免说教**：不要直接说出主题，要通过故事展现

## 5. 输出要求（必须严格执行）

### 5.1 大纲对齐自检（输出前执行）
- 逐条提取大纲中的情节点与“必须保留”的要点：关键动作/表情反应、关键台词、关键信息点、关键道具与其状态变化
- 对照剧本逐项核对：每条要点都应在对应场景中出现且功能一致，不得因“画面更好看”而删换
- 结尾重点复核：大纲用于角色弧线收束的最后动作/表情/反应必须出现；若要加钻石特写等镜头强化，只能叠加，不得挤掉原细节
- 自检过程不写进最终输出；仅在用户明确要求时，才额外给出对齐清单

### 5.2 角色清单
- 列出所有出场角色，信息完整度不低于大纲/用户输入，并补充可拍摄的外观要素，供分镜阶段复用
- 每个角色条目一行，信息到“可供分镜复用”为止即可，避免过细
- 字段建议：姓名 / 性别 / 年龄 / 身份 / 一句话定位（性格与功能合并描述）

示例：
- 林冕｜男｜27岁｜贵族子弟｜纨绔子弟，吃喝嫖赌无所不沾
- 苹儿｜女｜19岁｜小丫鬟｜慎雪莹的小丫鬟，聪明伶俐，娇俏可爱，善解人意

### 5.3 分场剧本
- 严格按照剧本格式规范输出
- 最终写入的 `.md` 必须使用统一 Markdown 层级：
  - 文件标题使用 `# {name}剧本`，其中 `name` 与输出文件 `{name}_剧本.md` 保持一致
  - `角色清单`、`分场剧本` 使用 `##`
  - 每个场景使用 `### 场景X：地点，时间，内/外`
  - 场景内字段统一写为 `**人物**：`
- 如需使用 `---` 作为 Markdown 分隔线，必须确保其前后各有一个空行；表格结束后也必须先空一行，再输出 `---` 或后续正文

### 5.4 输出模板
```
# {name}剧本

## 角色清单
- 角色A｜性别｜年龄｜身份｜一句话定位
- 角色B｜性别｜年龄｜身份｜一句话定位

## 分场剧本

### 场景1：地点1，时间，内/外。
**人物**：角色A、角色B、角色C
△动作行1-1
角色A（动作/表情/走位）：台词
角色B（动作/反应）：台词
△动作行1-2
角色A（动作/表情/走位）：台词
△动作行1-3
...

### 场景2：地点2，时间，内/外。
**人物**：xxx
△动作行2-1
△动作行2-2
角色A（动作/表情/走位）：台词
△动作行2-3
...

### 场景N：地点M，时间，内/外。
**人物**：xxx
...

```

#### 说明
1. 地点是“发生在哪里”，内/外是“摄影机所处空间”（同一地点既可能内景也可能外景）；地点字段只写主场所，不要把“展柜区/走廊/门口/舞池边”等子区域写进场景标题；如果是与故事时空不同的主观场景，可以在地点后加上主观场景类型后缀，如 客厅（回忆）/街道（幻觉）
2. 每个场景都必须写时间字段，室内和室外统一使用故事时段（如白天/夜晚/清晨/黄昏）；不要写灯光或画面状态（如“晚宴灯光/黑暗/应急红光”）；灯光变化写进△动作行；
3. 室外场景或涉及从室内看室外的场景，第一条△动作行必须补充天气信息，如晴、阴、雨、雪、雾等；纯室内场景不强制写天气。
4. **场景拆分原则**：仅当“时间”或“摄影机所处空间（内/外）”发生变化时，才新开场景标题；
  - **先判定是否同一物理空间**：不同叫法/包含关系（如“商场中庭”内含“快闪区/展台”）仍算同一场景；但是主观时空如闪回、回忆、幻觉、想象等是不同的场景
  - **同一空间内的小区域移动**：不拆场，用一条△动作行做衔接（如“站厅→闸机口旁检票通道”“地库→电梯厅门口”）
  - **需要强调子区域时**：用同一场景内的△动作行标注（如“△【展柜区】……”）；禁止把“大厅/大厅展柜区(大厅内)”这类“同地点+子区域”写成新场景标题
  - **人物增减/出入场**：不拆场，在“人物：”行合并列出本场景出场角色
  - **画面逻辑突变/灯光变化**：如灯光骤灭/警报响起/音乐停止/人群瞬间骚动；不拆场，用一条△动作行作为转折断点，直接承接后续动作与对话
5. **△动作行只写可拍到的内容**：环境 + 关键动作 + 关键道具/信息点（也可写停顿/欲言又止等可表演的状态），避免抽象抒情
6. 切换到主观时空需要有叙事标记，例如（闪回进入/结束），（想象进入/结束），（梦境进入/结束）等

### 5.5 时长预估

写入剧本后，根据剧本字数预估最终视频时长。
剧本字数与最终视频时长的对应关系（供创作时参考）：

| 剧本字数 | 预估时长 | 说明 |
|---------|---------|------|
| 500字 | 约1分钟 | 对话较多时约1分钟；对话较少、动作描写较多时可能仅几十秒 |
| 800字 | 约1分30秒 - 2分钟 | 标准故事短片的参考密度 |
| 1200字 | 约2分30秒 - 3分钟 | 适合情节较复杂或情感铺垫较长的短片 |

- 询问用户是否满意
- 根据反馈进行修改调整
