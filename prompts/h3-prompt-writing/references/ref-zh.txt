# 全参考模式（Ref2VA）改写输出格式指南

本指南说明全参考模式下的改写结果应当如何组织与撰写。

六个改写段落一律用中文书写。保持英文原样的只有标签：六个字段名、`[reference generation]` 一类任务类型前缀、`<Subject N>` / `<Picture N>` / `<Video N>` / `<Audio N>` 四类引用标签、`fully_preserved` 一类关系标记，以及 `[Shot N]` / `(Sx)` / `<d>` / `off-screen` 等结构标记；`<d>` 内的台词与歌词、画面中可见的文字，保留其原始语言。

**描述细节**：`detailed_description` 要尽可能详细、明确。每一个镜头都要交代清楚当前构图、主体外观与位置、环境与光线、动作与状态变化、镜头运动、当下声音，以及所引用内容真正出现或生效的位置。不要把描述退化成剧情梗概或一串引用关系清单。

> 镜头、镜头运动、说话人、台词、普通声音的基础格式，与《视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）》共用。本指南只讲全参考模式特有的引用标签、分析段落与格式差异。

## 输出通则

- 严格保留字段名、段落顺序、标签写法与时间标记。
- 每一个镜头都要按构图、主体、环境、动作、运镜、声音，以及引用内容出现的确切位置来写。
- 不写剧情梗概，不留悬空的引用标签，时间标记必须与要求的时长一致。
- 六段正文一律中文；除上面列出的固定标签外，不要夹写英文句子或英文段落。

## 1. 整体结构

一份完整的改写结果由以下六个段落按此顺序组成：

| 段落 | 作用 |
| --- | --- |
| `subject_definitions` | 定义被引用的内容及其引用标签 |
| `summary` | 概述任务类型、目标视频与主要引用关系 |
| `retention_analysis` | 说明引用内容如何被保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、声音与台词 |
| `overall_soundscape` | 归纳环境音与物理声 |
| `non_diegetic_music` | 描述只有观众能听见、角色听不见的配乐 |

## 2. 引用标签与定义（`subject_definitions`）

全参考改写使用四类标签标明引用内容的来源与作用：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出来、可在目标视频中复用或再加工的可视内容 |
| `<Picture N>` | 作为具体目标帧或分镜锚点的参考图片 |
| `<Video N>` | 提供剪辑来源、续接起点或整片时间结构的参考视频 |
| `<Audio N>` | 被复制或被引用的音频信号 |

> 某个引用标签一旦指派给一份内容，它在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 以及音频各段中都必须保持同一含义。

`subject_definitions` 定义每一份后续需要单独追踪的引用内容，例如某个人物、某个环境、某支源视频的结构或某条音轨。每一条单独成行，写明它的标签代表什么、承担什么引用角色、需要跟随的主要特征；需要交代来源时点名对应的源素材。如果 `<Picture N>` 或 `<Video N>` 只用来标明另一条引用项的来源，之后不会单独分析或使用，就把它写在那条定义内部，不要再单列一行。`retention_analysis` 则记录每个引用项出现在哪里，以及是完全保留、部分保留、迁移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可视内容，包括：

- 人物、动物或物件
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿态

它代表的是目标视频中真正会用到的内容单元，而不是源文件本身。一个主体可以由多份参考素材共同定义，一份参考素材也可以提供多个主体。

```text
<Subject 1> 是 <Picture 1> 中的年轻女性，深色长发、蓝色开衫、细银项链。
```

同一主体来自多份素材时，把来源合并写明各自提供了什么：

```text
<Subject 1> 是外形取自 <Picture 1>、行走动作取自 <Video 1> 的女性。
```

### 2.2 `<Picture N>`

当参考图片本身充当某镜头的首帧、关键帧、尾帧、剪辑关键帧或构图锚点时，单列一个 `<Picture N>`：

```text
<Picture 2> 是 [Shot 1] 的首帧，画面为一位女性坐在咖啡馆窗边。
```

如果图片只是用来定义角色、场景、服装或风格，不要单列图片条目，而应在对应的 `<Subject N>` 定义里注明图片来源。

当图片作为分镜或镜头规划参考时，写明它对应哪些镜头、提供了哪些规划信息：

```text
<Picture 3> 是 [Shot 1] 与 [Shot 2] 的分镜参考，规定两者的视点、主体位置与镜头顺序。
```

### 2.3 `<Video N>`

`<Video N>` 只用于整片层面的关系，例如：

- 剪辑一支原始视频
- 从一支原始视频的结尾继续
- 引用原始视频的运镜、剪辑、节奏或时间结构

```text
<Video 1> 是目标视频剪辑所用的源视频。
```

如果参考视频里的人物、物件、场景、动作或效果被当作可视内容复用，它仍归在 `<Subject N>` 下。`<Video N>` 标明的是素材或结构来源，不能替代主体标签。

### 2.4 `<Audio N>`

`<Audio N>` 代表一条独立的音频素材，或参考视频中启用的同步音轨。常见用途包括：

- 复制全部或局部音频信号
- 引用背景音乐风格
- 引用某位说话人的音色与表达方式
- 使用原音频中的台词、歌词或音效
- 引用节拍、节奏或音频连续性

当某个 `<Audio N>` 明确对应目标视频中的说话人时，在定义里复用该说话人的全局编号：说话人对应到已定义主体时写 `<Subject N> (Sx)`，否则用一段稳定的声线描述后接 `(Sx)`。编号取自目标视频的全局说话顺序，不在音频定义里另行指派或重排。说话人编号规则见第 5.4 节：

```text
<Audio 1> 是 <Subject 1> (S1) 的音色参考。
```

一条音频承担多个作用时，用一个自然句把这些作用写在一起，不要另拆小段。

### 2.5 同一支参考视频的画面轨与音频轨

`<Video N>` 与 `<Audio N>` 各自独立编号。下标只表示该标签在自己类别里的顺序，不表示两类之间的配对关系。因此同一支参考视频可以同时对应 `<Video 1>` 和 `<Audio 2>`，下标不同并不妨碍它们出自同一份素材。

普通参考视频不会因为文件里带声音就自动产生一个 `<Audio N>`。

`<Audio N>` 的定义主要写这条音频的作用，不必点名它来自哪一支 `<Video N>`；只有在来源可能产生歧义时才写明共同来源，例如：

```text
<Video 1> 是目标视频剪辑所用的源视频。
<Audio 2> 是 <Video 1> 的同步音轨，在目标视频中被复用。
```

## 3. `summary`

本段用一个简短的中文段落概述目标视频及其引用关系，开头要带方括号的任务类型前缀：

```text
[reference generation] 目标视频依据 <Picture 1> 生成……
[video editing + reference generation + audio reuse] 目标视频剪辑自 <Video 1>，并复用 <Audio 1>……
```

按每份参考素材在目标视频中实际承担的作用选择任务类型：

| 任务类型 | 何时使用 |
| --- | --- |
| `keyframe completion` | 图片充当目标视频的首帧、关键帧、尾帧、剪辑关键帧或其它具体帧锚点 |
| `reference generation` | 图片、视频或音频为角色、场景、风格、动作、运镜、分镜等提供生成指引，但不作为具体帧，也不是被剪辑或被续接的源视频 |
| `video editing` | 直接修改一支已有的源视频；编辑图片或在静帧关键帧之间生成不属于此类 |
| `video continuation` | 新内容从已有源视频继续、延伸、接续或过渡 |
| `audio reuse` | 同一段音频信号被完整或部分复用 |
| `audio reference` | 不直接复制音频信号，只引用其音乐风格、音色、台词或歌词内容、音效质感、节拍或连续性 |

一个任务同时满足多种关系时，用 ` + ` 连接任务类型，且不要重复同一类型。例如：从源视频续接、同时用一张图作尾帧，写作 `[video continuation + keyframe completion]`；剪辑源视频并保留原声，可写作 `[video editing + audio reuse]`。

仅仅出现了视频或音频，并不自动产生对应的任务类型。参考视频若只提供运镜、剪辑或节奏，通常归为 `reference generation`；只有该视频被直接剪辑或续接时才用 `video editing` 或 `video continuation`。

剪辑源视频时，若原声仍可听见，同时用 `audio reuse`；续接源视频但没有直接复制音频信号、只是延续原音轨的听感特征时，用 `audio reference`。

`summary` 使用前面已经定义好的 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 标签来概述主要主体、镜头流程与参考素材的作用。本段不得引入新的引用标签。

剪辑类任务的 `summary`，在任务类型前缀之后要以下面这句开头：

```text
目标视频是 <Video 1> 的剪辑版本。
```

## 4. `retention_analysis`

本段说明每一份引用内容在目标视频中如何被保留、迁移、复制或引用。每个引用标签单独一行，并保持 `subject_definitions` 里确立的含义。

### 4.1 可视内容

`<Subject N>`、`<Picture N>`、`<Video N>` 使用下列关系标记。这些标记是输出格式中固定的英文取值：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 引用内容所定义的角色被完整保留 |
| `partially_preserved` | 引用内容仍在使用，但部分已定义特征被改动或只保留了一部分 |
| `attribute_transfer` | 被引用的特征迁移到另一个可辨认的目标主体上 |
| `weak_reference` | 只保留风格、类别、构图或氛围上的宽泛相似 |

主体条目：

```text
<Subject 1>（出现于 [Shot 1]、[Shot 3]）：fully_preserved - ……
```

图片条目：

```text
<Picture 2>（[Shot 1] 首帧）：fully_preserved - ……
```

视频结构条目：

```text
<Video 1>（剪辑与节奏结构）：weak_reference - ……
```

### 4.2 音频

`<Audio N>` 使用下列关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整源音频作为目标视频最终的完整音轨 |
| `partially_copy` | 只复制部分时间线或选定音频层，或在复制之后增删、替换了其它声音 |
| `reference` | 不直接复制信号，只引用音色、节奏、音乐风格、台词内容或声音质感 |
| `weak_reference` | 只保留类别或氛围上的宽泛相似 |

```text
<Audio 1>：fully_copy - <Audio 1> 以 1:1 复用为目标视频的完整最终音轨。
```

```text
<Audio 2>：reference - 目标说话人沿用 <Audio 2> 的音色与克制的表达方式，但不复制原信号。
```

关系标记只能在 `subject_definitions` 为该标签已定义的引用角色范围内选择。不要把目标视频里新增的动作、背景或情节事件当成引用保真度的损失。

## 5. `detailed_description`

这是全参考改写的主体。它按目标视频的播放顺序逐镜头描述画面、动作、声音与台词，并在适用处插入引用标签。

### 5.1 基础格式

基础格式沿用《视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）》：

- 正文用中文书写；台词、歌词与画面可见文字保留原语言。
- `[Shot 1]` 标记开场镜头，不带时间戳；后续镜头用 `[Shot N] 在 MM:SS.mmm，……` 标出切点时间。
- 镜头运动用当前镜头里的自然中文表述，需要时交代运动类型、幅度与速度。
- 为发声来源分配稳定的 `(S1)`、`(S2)` 等编号。台词与歌词写成 `<d>[Language] ...</d>`。
- 台词跨切点、被片尾截断、以及跨镜头连续的声音，分别用 `<scenetrans>`、`<cutoff>` 与对应的连续性描述。

运镜词汇、群体说话、画外音、跨切点台词与画面可见文字的完整规则与示例，见《视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）》。

### 5.2 与全参考模式的差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 之前用一两句中文确立 |
| 引用信息 | 不使用全参考标签 | 在首次出现及作用生效处插入 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 `<Audio N>`，并说明信号是复制还是引用 |

开场示例：

```text
目标视频为电影感、文艺气的音乐视频风格，光线柔和、色彩略微去饱和。
[Shot 1] 场景在拥挤的城市街道中展开……
[Shot 2] 在 00:09.000，镜头切至一处极近特写……
```

生成类任务的 `detailed_description` 通常为 350-500 字。台词密集的内容优先保证把完整的说话时间线写全，不必机械凑字数。剪辑类描述随源视频复杂度伸缩，不一定要遵守生成任务的字数区间。单个镜头并不自动意味着可以写得更短；要按各镜头的信息量分配细节。

### 5.3 在镜头中使用引用标签

重要的 `<Subject N>` 首次清晰出现时，要写出它的被引用特征、画面中的位置，以及该镜头中实际可见的动作。后续镜头继续沿用同一标签，不要重新定义标签所指。

具体帧锚点用自然措辞：

```text
镜头从 <Picture 1> 开始
镜头的关键帧对应 <Picture 2>
镜头结束于 <Picture 3>
```

剪辑或续接原始视频时，在来源状态、结构或续接关系生效处自然引用 `<Video N>`。在音频关系生效的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话人、声源与台词

说话人编号与 `<d>` 的基础格式沿用 T2VA。被引用主体真的开口说话时，同时保留可视引用标签与说话人编号：

```text
<Subject 2> (S1) 转向那位女性并说道：<d>[Chinese] 去年夏天，我去了外公家。他提到了你。</d>
```

`<Subject N>` 标明被引用主体，`(Sx)` 标明实际说话人。主体说话时写 `<Subject N> (Sx)`；同一主体在画外说话时保持同样写法并标注 `off-screen`。说话人没有对应到已定义主体时，用一段稳定的声线描述后接 `(Sx)`。

当人声内容只是被直接复用的 BGM 或完整音轨里的一个提示点，且没有人、角色、旁白或其它独立发声来源真的发出它时，用 `<Audio N>` 作为可听来源，不要另造一个 `(Sx)`。若确由某个具体人物、角色、旁白或其它独立发声来源发出，则为该来源分配并复用 `(Sx)`：

```text
当 <Audio 1> 播放到 <d>[Chinese] 我好孤单，好孤单……</d> 这一句时，<Subject 1> 做出相应手势，不另行构成一个说话人来源。
```

直接复用参考音频中的台词、旁白或歌词，或输入提示词明确要求重新演绎时，要在 `<d>` 内逐字保留原词与原语言。听不清的片段写 `[unclear]`，不要猜测或转述。标点统一成表意所需的基本书面符号，如 `,`、`.`、`?`、`!`；删掉重复的波浪号、表情符号、项目符号以及重复或装饰性标点。完整陈述、疑问句、感叹句在 `</d>` 之前分别以 `.`、`?`、`!` 收尾。

只引用音色、节奏、情绪或表达方式时，不要把参考音频里的原台词带进目标视频。

`(Sx)` 按目标视频中实际发声事件出现的顺序各分配一次，并在 `detailed_description` 的每一次实际发声事件上复用；`subject_definitions` 里绑定到目标说话人的 `<Audio N>` 定义也复用同一个 `(Sx)`，但绝不独立新分配。`retention_analysis` 里不要写 `(Sx)`。只存在于被直接复用的 BGM 或完整音轨里的人声提示用 `<Audio N>`；由具体人物、角色、旁白或其它独立发声来源真实发出的声音用 `(Sx)`。

## 6. `overall_soundscape` 与 `non_diegetic_music`

这两类声音的定义沿用《视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）》。

`overall_soundscape` 归纳整片的环境音与物理声。台词、演唱以及与特定镜头同步的声音事件仍留在 `detailed_description`：

```text
overall_soundscape: 全片持续安静的室内环境底噪与低沉的通风嗡鸣。
```

`non_diegetic_music` 描述角色听不见、只有观众能听见的背景音乐。有音乐时要写明配器、速度与动态发展；没有配乐时写「无」：

```text
non_diegetic_music: 克制的钢琴独奏，速度缓慢，下方铺持续的低音大提琴，不做渐强。
```

使用参考音频时，只在与可听层对应的段落里写明它的复制或引用关系：环境音与音效归 `overall_soundscape`，观众专属配乐归 `non_diegetic_music`。同一条音频同时提供两类内容时，在各自段落里分别描述对应关系：

```text
overall_soundscape: 从 <Audio 1> 复制的环境声层贯穿目标视频。
non_diegetic_music: <Audio 2> 被直接复用为完整的观众专属配乐。
```

完整的台词与歌词只写在 `detailed_description` 的 `<d>` 里，不要在这两段中重复。

## 7. 完整示例

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡馆环境，红砖裸墙、橙色拉扣沙发配花纹抱枕、霓虹灯牌和木质咖啡桌。
```
