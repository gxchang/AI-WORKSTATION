# AI WORKSTATION

一个跑在自己电脑上的 AI 创作工作台。

**先说最重要的一点：这东西本身不生成任何东西。** 它只是个界面加流程管理，出图、出视频、配音  
全都要调外部接口。你得自己去申请（Agnes、魔搭 ModelScope、火山方舟，或者任何 OpenAI 兼容的服务），  
把地址和密钥填进设置里才能开始用。项目里不带模型，也不含额度，不配接口的话界面能打开，  
但什么都生成不出来。

数据都留在本地：会话、素材、密钥都在你自己的电脑上。生成的时候，提示词和你选的参考图会发给你配的那家服务商。

## 功能

| 模块     | 说明                                                                                   |
| ------ | ------------------------------------------------------------------------------------ |
| 对话生成   | 在对话里填入你的脚本直接出图、出视频、配音，结果就留在对话里                                                       |
| 画布     | 把素材、文本、生成、合成摆成节点连起来，可视化操作方便快捷直观                                                      |
| 图片编辑   | 多机位九宫格、剧情推演四宫格、多角度、打光、宫格切分                                                           |
| 视频合成   | 画布内节点直接使用，面板双轨时间线，拖拽排序、剪裁、吸附、全屏编辑，导出成片                                               |
| 长视频工作台 | 按剧本走：登记素材、生成分镜、逐镜出片、分镜时会根据模型最大支持时长自动完成预留续接段抽帧索引保持上下场景角色一致性，生成结果自动合成长视频               |
| 资产库    | 生成和上传的东西都在这，任务删除不受影响，你可以在这里对生成结果进行管理                                                 |
| 悬浮猫灵助手 | 一个能自己调工具的助手，可以让它直接出图或出片，你在这里可以跟它聊天，它会识别你的意图帮你进行创作，助手暂不具备出网条件，助手可联动长视频工作台完成长视频从0-1的制作 |
| 多服务商   | 生图、视频、配音、助手、分镜可以分别指定不同服务商                                                            |

## 快速开始

需要 Python 3.10 以上。没装也不用管，启动器会自己装（Windows 走 winget，macOS 走 Brew，  
可能会弹一次授权窗口）。如果自己装，记得勾上 `Add python.exe to PATH`，另外别用微软商店里的那个  
python，它是个空壳，能"找到"但跑不起来。

| 平台            | 怎么起                                                                                  |
| ------------- | ------------------------------------------------------------------------------------ |
| Windows       | 解压后双击 `start.bat`                                                                    |
| macOS / Linux | `./start.sh`                                                                         |
| 想手动跑          | `pip install -r requirements.txt`，然后 `python server.py`，浏览器开 <http://127.0.0.1:5000> |

第一次启动要联网装依赖和 ffmpeg，一两分钟；之后每次都是秒开。电脑上已经有的 Python 环境和 ffmpeg  
会直接用，不重复装，也不改你的系统设置。

起来之后，点左下角「服务商设置」，把接口地址和密钥填进去，保存就生效，不用重启。没填密钥时界面  
能正常逛，但生成会失败。密钥只存在本地数据库 `data/app.db`，也支持写进 `.env` 或系统环境变量。

## 注意事项

- 不带模型，也不做本地推理，所有生成都是调你配的接口。
- 提交生成时，提示词和你选的参考图会发给那家服务商。
- 会话、素材、密钥都存在本地（`data/` 和 `storage/`）。
- 没有登录，也没有权限控制。就一个人用，别挂到公网上；多人共用一个实例会共用同一份数据和密钥。
- 能不能生成、生成多少，取决于你配的那家接口是否可用、有没有额度。

## 常见问题

**端口被占用了？** 启动器改 `AIWS_PORT`（Windows 上 `set AIWS_PORT=8080`）；手动跑 `python server.py` 的改成 `PORT=8080`。

**依赖装不上或者很慢？** 加国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

**视频合成之类的功能不能用？** 大概率是 ffmpeg 的问题。启动器会提示它用的是哪一个；有些精简版  
（比如 Krita 自带的）处理不了中文文件名，会让缩略图、时长探测、拼接失效。这时跑一次  
`start.bat --get-ffmpeg` 换成官方版，或者手动把 `ffmpeg.exe`、`ffprobe.exe` 放进 `bin/` 目录。

**想让服务重启一下？** `start.bat --force`。
